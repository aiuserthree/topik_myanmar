## 상세 기능 설명

### 1. 통계 카드 (Stats Card)

#### 1.1 오늘 발송 건수
```
┌─────────────────────────────────┐
│ 오늘 발송 건수          📧      │
│ ───────────────────────────────│
│ 12,345                         │
│ ↗ 전일 대비 +5.2%              │
└─────────────────────────────────┘
```
- **데이터 소스**: 당일 00:00 ~ 현재 발송 완료 건수
- **갱신 주기**: 페이지 로드 시, 5분 간격 자동 갱신
- **클릭 액션**: 발송 내역 모니터링 페이지로 이동

#### 1.2 오늘 충전 금액
```
┌─────────────────────────────────┐
│ 오늘 충전 금액          💰      │
│ ───────────────────────────────│
│ ₩5,678,900                     │
│ ↗ 전일 대비 +12.3%             │
└─────────────────────────────────┘
```
- **데이터 소스**: 당일 00:00 ~ 현재 충전 완료 금액
- **클릭 액션**: 충전 내역 페이지로 이동

#### 1.3 오늘 신규 가입자
```
┌─────────────────────────────────┐
│ 오늘 신규 가입자        👥      │
│ ───────────────────────────────│
│ 23                             │
│ ↗ 전일 대비 +8.7%              │
└─────────────────────────────────┘
```
- **데이터 소스**: 당일 00:00 ~ 현재 가입 완료 회원 수
- **클릭 액션**: 회원 관리 페이지로 이동

#### 1.4 승인 대기 건수
```
┌─────────────────────────────────┐
│ 승인 대기 건수          ⏳      │
│ ───────────────────────────────│
│ 15                             │
│ 발신번호: 8건  템플릿: 7건      │
└─────────────────────────────────┘
```
- **데이터 소스**: 현재 승인 대기 상태인 발신번호 + 템플릿 건수
- **클릭 액션**: 발신번호 승인 대기 페이지로 이동

#### 1.5 처리 대기 문의
```
┌─────────────────────────────────┐
│ 처리 대기 문의          💬      │
│ ───────────────────────────────│
│ 7                              │
│ 긴급: 2건                      │
└─────────────────────────────────┘
```
- **데이터 소스**: 미답변 + 답변 대기 문의 건수
- **긴급 기준**: 우선순위 '긴급' 설정된 문의
- **클릭 액션**: 문의 관리 페이지로 이동

#### 1.6 시스템 상태
```
┌─────────────────────────────────┐
│ 시스템 상태             ✅      │
│ ───────────────────────────────│
│ 정상                           │
│ 모든 서비스 정상 운영           │
└─────────────────────────────────┘
```
- **상태 유형**:
  - 정상 (녹색): 모든 시스템 정상 운영
  - 경고 (노란색): 일부 지연 또는 경고 상황
  - 오류 (빨간색): 시스템 장애 발생
- **클릭 액션**: 시스템 설정 페이지로 이동

### 2. 최근 발송 내역 테이블

#### 2.1 테이블 컬럼 정의
| 컬럼명 | 설명 | 정렬 | 형식 |
|--------|------|------|------|
| 발송일시 | 발송 시작 일시 | 내림차순 | YYYY-MM-DD HH:mm |
| 회원 | 발송 요청 회원 | - | 이름 (이메일) |
| 메시지 타입 | 발송 메시지 유형 | - | 뱃지 (색상 구분) |
| 발송 건수 | 총 발송 요청 건수 | - | 숫자 (천단위 콤마) |
| 성공 | 발송 성공 건수 | - | 숫자 |
| 실패 | 발송 실패 건수 | - | 숫자 |
| 상태 | 현재 발송 상태 | - | 뱃지 |

| 타입 | 색상 | 클래스 |
|------|------|--------|

| LMS | 회색 | badge-secondary |
| MMS | 회색 | badge-secondary |
| 알림톡 | 파란색 | badge-info |
| 브랜드톡 | 노란색 | badge-warning |

#### 2.3 상태 뱃지 색상
| 상태 | 색상 | 클래스 |
|------|------|--------|
