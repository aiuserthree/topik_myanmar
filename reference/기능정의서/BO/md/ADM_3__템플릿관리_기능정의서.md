## 상세 기능 설명

### 1. 탭 구조

```
┌────────────┬────────────┬────────────┬────────────┐
│ 검수 대기  │  검수 중   │ 승인 완료  │    반려    │
│    (7)     │    (3)     │   (15)     │    (5)     │
└────────────┴────────────┴────────────┴────────────┘
```

#### 1.1 탭별 상태 매핑
| 탭 | 상태 코드 | 설명 |
|---|---------|------|
| 검수 대기 | PENDING | 내부 검수 대기 중 |
| 검수 중 | REVIEWING | 카카오 검수 요청됨, 결과 대기 중 |
| 승인 완료 | APPROVED | 카카오 승인 완료, 사용 가능 |
| 반려 | REJECTED | 내부 또는 카카오 검수 반려됨 |

### 2. 검수 대기 목록

#### 2.1 테이블 컬럼
| 컬럼명 | 설명 | 너비 |
|--------|------|------|
| 신청일시 | 템플릿 등록 신청일 | 130px |
| 회원 정보 | 회원명 + 이메일 | 180px |
| 발신프로필 ID | @아이디 형태 | 120px |
| 템플릿명 | 템플릿 이름 | 200px |
| 템플릿 코드 | 고유 코드 | 150px |

function rejectTemplate() {
    const reason = document.querySelector('#templateRejectModal textarea').value;
    
    if (!reason.trim()) {
        showToast('반려 사유를 입력해주세요.', 'error');
        return;
